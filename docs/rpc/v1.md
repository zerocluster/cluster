# RPC v1

### API connect URLs

- API HTTP URL: `http://cluster:81/`
- API WebSockets URL: `ws://cluster:81/`

<!-- tabs:start -->

#### **WebSockets**

```javascript
import Api from "@corejslib/core/api";

const api = new Api( "ws://cluster:81/" );
```

#### **HTTP**

```javascript
import Api from "@corejslib/core/api";

const api = new Api( "http://cluster:81/" );
```

<!-- tabs:end -->

## PostgreSQL

### Get WAL file

<!-- tabs:start -->

#### **JavaScript**

```javascript
const res = await api.call( "/v1/postgresql/get-wal", server_names );
```

#### **Shell**

```sh
curl \
    -H "Authorization: Bearer <YOUR-API-TOKEN>" \
    "http://cluster:81/v1/postgresql/get-wal"
```

<!-- tabs:end -->

- `server_names`

<details>
    <summary>JSON schema</summary>

<!-- tabs:start -->

#### **JSON**

```json
{
    "anyOf": [
        {
            "type": "string",
            "format": "nginx-server-name"
        },
        {
            "type": "array",
            "items": {
                "type": "string",
                "format": "nginx-server-name"
            },
            "minItems": 1,
            "uniqueItems": true
        }
    ]
}
```

#### **YAML**

```yaml
anyOf:
  - type: string
    format: nginx-server-name
  - type: array
    items:
      type: string
      format: nginx-server-name
    minItems: 1
    uniqueItems: true
```

## Service discovery

### Register host services

<!-- tabs:start -->

#### **JavaScript**

```javascript
const res = await api.call( "/v1/service-discovery/set-host-services", options );
```

#### **Shell**

```sh
curl \
    -H "Authorization: Bearer <YOUR-API-TOKEN>" \
    "http://cluster:81/v1/service-discovery/set-host-services"
```

<!-- tabs:end -->

- `options` {Object}

<details>
    <summary>JSON schema</summary>

<!-- tabs:start -->

#### **JSON**

```json
{
    "type": "object",
    "properties": {
        "version": {
            "type": "integer",
            "minimum": 1
        },
        "appName": {
            "type": "string",
            "format": "kebab-case"
        },
        "services": {
            "type": "object",
            "propertyNames": {
                "type": "string",
                "format": "kebab-case"
            },
            "additionalProperties": {
                "type": "object",
                "properties": {
                    "hostname": {
                        "type": "string",
                        "format": "domain-name"
                    },
                    "port": {
                        "type": "integer",
                        "format": "ip-port"
                    },
                    "pathname": {
                        "type": "string",
                        "format": "absolute-path"
                    }
                },
                "additionalProperties": false,
                "required": [
                    "port",
                    "pathname"
                ]
            }
        }
    },
    "additionalProperties": false,
    "required": [
        "version",
        "appName",
        "services"
    ]
}
```

#### **YAML**

```yaml
type: object
properties:
  version:
    type: integer
    minimum: 1
  appName:
    type: string
    format: kebab-case
  services:
    type: object
    propertyNames:
      type: string
      format: kebab-case
    additionalProperties:
      type: object
      properties:
        hostname:
          type: string
          format: domain-name
        port:
          type: integer
          format: ip-port
        pathname:
          type: string
          format: absolute-path
      additionalProperties: false
      required:
        - port
        - pathname
additionalProperties: false
required:
  - version
  - appName
  - services
```

<!-- tabs:end -->

</details>
